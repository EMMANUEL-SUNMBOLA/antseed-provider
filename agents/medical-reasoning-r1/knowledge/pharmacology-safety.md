# Pharmacology Safety — Checks Before Any Dose Answer

Rule: **no dose statement without the patient factors that justify it.** If the
factors aren't given, state the standard assumptions explicitly ("assuming
normal renal/hepatic function, adult 60-80 kg") and list what would change the
answer.

## The universal pre-dose checklist

1. **Indication & line** — is this drug appropriate for this problem, and is
   oral/IV/IM the right route for this severity?
2. **Allergies** — ask; note reaction type (rash vs anaphylaxis changes the
   class decision).
3. **Age & weight** — pediatric dosing is weight-based (state the convention:
   mg/kg, BSA, or age band); geriatric starts low ("start low, go slow") for
   sedatives, anticholinergics, antihypertensives, hypoglycemics.
4. **Renal function** — estimate CrCl/Cockcroft-Gault or note eGFR; list the
   drugs in the plan that need renal adjustment.
5. **Hepatic function** — Child-Pugh class or synthetic function; flag
   high-hepatic-clearance drugs.
6. **Pregnancy & lactation** — check category/compatibility; many drugs are
   contraindicated or require specialist input (e.g. methotrexate,
   warfarin, ACE inhibitors, tetracyclines in pregnancy).
7. **Interactions** — reconcile against the full med list **including OTC and
   supplements** (the classic misses: NSAIDs + anticoagulants/ACEi/diuretics,
   St John's wort + almost everything, macrolides/azoles + QT-prolongers,
   grapefruit juice + CYP3A4 substrates).
8. **Duplicates & class stacking** — two drugs same class (two NSAIDs, two
   benzos) is a common prescribing error.
9. **Monitoring & stop criteria** — what lab/vital/symptom check confirms it
   works and catches toxicity, and when to stop.

## High-alert medications — always show the check

| Class | Never skip |
|---|---|
| Insulin / sulfonylureas | Hypoglycemia risk factors, renal dosing, sick-day rules, timing vs meals |
| Anticoagulants (heparin, warfarin, DOACs) | Indication-specific dosing tables, renal cutoffs (e.g. DOAC CrCl limits), interactions, reversal plan |
| Opioids | Pain plan vs dependence risk, co-prescribed naloxone consideration, respiratory depression risk (elderly, OSA, concurrent sedatives) |
| Chemotherapeutics / immunosuppressants | Protocol-based dosing only; BSA/AUC; specialist supervision; fertility and infection prophylaxis |
| IV push / concentrated electrolytes | Dilution, rate limits, line checks (never IV push undiluted KCl/Mg), continuous monitoring requirements |
| Antibiotics (empiric) | Local resistance patterns, cultures first when feasible, de-escalation plan, dose for site (e.g. bone/soft-tissue penetration) |

## Interaction classes worth memorizing

- **CYP inhibitors/inducers:** azoles, macrolides, ritonavir (inhibitors);
  rifampin, carbamazepine, phenytoin, St John's wort (inducers).
- **QT prolongation:** macrolides, fluoroquinolones, ondansetron IV, antipsychotics,
  antiarrhythmics — stack risk is multiplicative.
- **Serotonin:** SSRI/SNRI + triptan + tramadol + linezolid + MAOI washouts.
- **Nephrotoxin stacking:** NSAID + ACEi/ARB + diuretic ("triple whammy");
  aminoglycosides + vancomycin + contrast.
- **Anticoagulant amplifiers:** NSAIDs, antiplatelets, SSRIs (bleed risk),
  amiodarone (INR/DOAC levels).
- **Warfarin food/vitamin K:** consistency over avoidance; document the
  conversation.

## OTC / supplement pitfalls (ask every time)

NSAIDs (renal, GI, BP, anticoagulant interaction), acetaminophen cumulative
dose (hepatic, alcohol use), decongestants (BP, arrhythmia), antihistamines
(anticholinergic burden in elderly), magnesium/antacids (absorption),
iron + thyroid + fluoroquinolone/tetracycline separation, cannabis products
(CYP3A4, sedation), "energy" blends with hidden stimulants.

## Dose-answering format

When asked for a dose, answer as:

```
Drug — indication
Standard adult dose: X mg [route] [frequency] [duration]
Adjust: renal (CrCl thresholds) / hepatic / weight / age / pregnancy
Interactions that matter here: ...
Monitor: ...
Counsel: ...
```

…and explicitly flag anything that requires pharmacist/protocol verification
in the user's jurisdiction. Dose tables change; present them as
"typical convention, verify against current formulary" — never as certainty.

## What you refuse

- Weight-based pediatric dosing without weight and age band.
- Chemotherapy or immunosuppression dosing outside published protocols.
- Compounding, dilution, or administration instructions for high-alert IV
  drugs beyond standard references (rate/dilution must follow local protocol).
- Adjusting anticoagulants without labs and indication details.
- Any request to invent a plausible-looking dose to satisfy a template.
