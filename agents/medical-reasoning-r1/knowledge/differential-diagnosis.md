# Differential Diagnosis — Risk-First Method

The goal of a differential is not a list; it is a **risk-ranked plan**. Order by
`likelihood × severity`, and never let a common-but-benign explanation crowd
out a rare-but-lethal one until that lethal one is explicitly ruled out.

## Step 1 — Red-flag screen (always first)

Screen these before deep reasoning; any positive jumps the problem to
**emergency/urgent** and reshapes everything after it.

| Domain | Red flags |
|---|---|
| Cardiovascular | Chest pressure/tearing pain, exertional angina, syncope with exertion, new murmur + fever, hypotension, irregular pulse with instability |
| Neurologic | Focal deficit (FAST-positive), thunderclap headache, new confusion, seizure without history, meningismus, gait loss |
| Respiratory | SpO2 low for baseline, accessory-muscle use, tripoding, hemoptysis, unilateral absent breath sounds + hypotension |
| Infection/Sepsis | Fever + confusion or hypotension, rigors with tachycardia, purpura, neutropenic fever, post-partum fever, toxic appearance |
| Abdominal | Rigid/peritoneal, pain out of proportion to exam, pain with syncope, distension + vomiting, GI bleeding with instability |
| Bleeding | Hemodynamic compromise, ongoing bleeding, known anticoagulation, pregnancy + abdominal pain/bleeding |
| Psychiatric | Suicidal or homicidal ideation, plan or intent, inability to maintain safety, psychosis with distress |
| Obstetric | Headache/vision changes + hypertension, abdominal pain + bleeding, decreased fetal movement, post-partum chest pain/dyspnea |
| Pediatric | Age <3 months with fever, lethargy, poor perfusion, petechiae, bulging fontanelle, respiratory distress, dehydration with lethargy |
| Metabolic | Altered mental status + known diabetes on insulin/SU, K>6 or Na<125 on history, DKA symptoms, adrenal crisis clues |

## Step 2 — Frame the problem in one line

`(age, sex, pregnant?) · tempo (hyperacute / acute / subacute / chronic) ·
key syndrome + 2-3 discriminators` — e.g. "42F, acute, pleuritic chest pain +
tachycardia + OCP use → PE pretest elevated."

## Step 3 — Build the differential (three buckets)

1. **Can't-miss (severity-first):** the emergencies for this syndrome, even if
   unlikely. State each with the one finding that would raise its probability.
2. **Common (base-rate-first):** the diagnoses that explain most cases of this
   presentation in this population.
3. **Occult/zebra (pattern-matches):** only include when something atypical
   points there (travel, immunosuppression, family history, refractory course).

Each entry gets: `working label · likelihood (high/mod/low) · key supporting
findings · key against · next discriminating test or finding`.

## Step 4 — Discriminate, then quantify

- Prefer the finding/test that **changes management**, not just probability.
- Use pretest likelihood honestly. Example framing: "Wells low → PE
  pretest ~3%; PERC negative → essentially excluded." Use conventional
  thresholds, and name the convention when a number is load-bearing.
- Bayes in words: what finding moves this from "possible" to "probable", and
  what moves it out entirely?

## Step 5 — Close the loop

End every diagnostic answer with:

- **Disposition** — emergency / same-day / outpatient; specialist involvement.
- **What would change my mind** — the 1-3 findings or results that would
  re-rank the list.
- **Safety net** — what the patient/clinician should watch for and by when.

## Population modifiers (never skip silently)

- **Pregnancy/post-partum:** PE, amniotic fluid embolism, preeclampsia,
  HELLP, peripartum cardiomyopathy, endometritis, ovarian torsion.
- **Immunocompromised:** blunted fever, atypical organisms, abscess until
  proven otherwise, opportunistic infection by exposure history.
- **Elderly:** atypical presentations (afebrile infection, "not acting right",
  falls, delirium), polypharmacy effects, less physiologic reserve.
- **Pediatric:** congenital/structural causes, Kawasaki, intussusception,
  testicular/ovarian torsion, occult bacteremia by age band.
- **Renal/hepatic impairment:** altered drug handling changes both treatment
  and the differential (uremia, hepatorenal, encephalopathy).

## Anti-patterns

- Anchoring on the first plausible diagnosis before the red-flag screen.
- Listing 12 diagnoses with no ranking and no discriminating plan.
- Ordering tests "to be safe" that change nothing about disposition.
- Treating a normal first-line test as definitive when pretest was moderate-high.
- Forgetting the base case (infection, medication effect, metabolic derangement)
  in the rush for zebras.
